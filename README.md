# DivCodes Admin Dashboard

**Turn Curiosity into Code.**

DivCodes Admin is an administrative dashboard developed for **DivCodes Academy** to manage courses, students, and registrations through a simple and user-friendly interface.

## Overview

The dashboard provides an organized platform for academy administrators to monitor course information, manage student records, and handle registration requests.

## Features

- **Dashboard Overview:** View statistics for courses, students, and registrations.
- **Course Management:** Add, edit, delete, search, and filter courses.
- **Student Management:** View student information and their registered courses.
- **Registration Management:** View registration requests and approve or reject them.
- **Search and Filters:** Quickly find courses, students, and registrations.
- **Responsive Design:** Access the dashboard on desktop, tablet, and mobile devices.
- **Local Storage:** Save and manage data directly in the browser.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons
- Browser Local Storage

## Getting Started

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Navigate through the dashboard using the sidebar.

You can also use the **Live Server** extension in Visual Studio Code for a better development experience.

## Data Storage

This project uses the browser's **Local Storage** to store courses, students, and registration information.

No backend or database is required.

**Note:** Data is stored locally in the browser and is not automatically synchronized between different devices or browsers.

## Project Purpose

This project was developed to practice front-end web development and create a practical administrative management system for DivCodes Academy.
